01 • FUNDAMENTALS

Functions — Basic Concepts

Before studying different types of functions, it is important to understand what a function actually means and how it is represented mathematically.

What is a Function?

A function is a special type of relation between two sets in which every element of the first set, called the domain, is associated with exactly one element of the second set, called the codomain.

If A and B are two sets, a function from A to B is written as f : A → B. This notation means that function f maps every element of A to one and only one element of B.

f : A → B

The important phrase to remember is “every input has exactly one output.” Several different inputs may produce the same output, but one input cannot produce two different outputs.

Function as a Relation

A relation is a collection of ordered pairs. A function is a relation with an additional restriction: no input value can be paired with two different output values.

Function:

{(1, a), (2, b), (3, c)}

Not a function:

{(1, a), (1, b), (2, c)}

Here input 1 has two outputs: a and b.

Ways to Represent a Function

A function can be represented in several ways. Understanding these representations helps students move between mathematical notation, diagrams, tables and graphs.

01

Mapping Diagram

Elements of the domain are connected to their corresponding elements in the codomain using arrows.

02

Ordered Pairs

A function can be represented as a set of ordered pairs, such as {(1,2), (2,4), (3,6)}.

03

Formula

A rule can define a function, such as f(x) = 2x + 1.

04

Table

Input and output values can be arranged in a table.

05

Graph

A function can be plotted on a coordinate plane to visualize the relationship between input and output.

✎

14-Mark Exam Point

When asked “Define a function and explain its representation”, begin with the formal definition, explain domain and codomain, write f : A → B, give an example using ordered pairs or a mapping diagram, and clearly state the rule: each domain element must have exactly one image.

02 • CORE CONCEPT

Domain, Codomain and Range

These three terms describe different parts of a function. Students often confuse codomain with range, so they should be studied separately.

D

Domain

The domain is the set of all possible input values for a function. In a function f : A → B, the set A is the domain.

Domain = Set of inputs

For example, if f(x) = x² and the allowed inputs are {-2,-1,0,1,2}, then these five values form the domain.

C

Codomain

The codomain is the set that contains all possible target values specified when the function is defined.

f : A → B
B = Codomain

The codomain may contain values that are never actually produced by the function.

R

Range

The range is the set of output values that are actually obtained from the domain.

Range ⊆ Codomain

Therefore, every range value belongs to the codomain, but every codomain value need not necessarily belong to the range.

Domain vs Codomain vs Range

Concept Meaning Question to Ask
Domain Set of input values What can I put into the function?
Codomain Specified target set Where can outputs belong?
Range Actual output values What outputs are actually produced?

03 • CLASSIFICATION

Types of Functions

Functions can be classified according to how elements of the domain are mapped to elements of the codomain.

01

Injective

A function is injective or one-to-one if distinct elements of the domain always have distinct images.

f(a) = f(b) ⇒ a = b
One-to-One
02

Surjective

A function is surjective or onto when every element of the codomain is the image of at least one domain element.

Range = Codomain
Onto
03

Bijective

A bijective function is both injective and surjective. Every codomain element has exactly one pre-image.

Bijective = Injective + Surjective
One-to-One & Onto
04

Many-to-One

A many-to-one function allows two or more different domain elements to have the same image.

a ≠ b but f(a) = f(b)
Allowed
05

Into

An into function does not cover the entire codomain. Therefore at least one codomain element is not an image.

Range ⊂ Codomain
Not Onto
06

Identity Function

An identity function maps every element to itself.

f(x) = x
Special Function

04 • ONE-TO-ONE

Injective Functions

An injective function is also called a one-to-one function. It never assigns the same output to two different inputs.

Definition

Let f : A → B be a function. The function f is called injective if whenever two domain elements have the same image, those domain elements must actually be equal.

f(a) = f(b) ⇒ a = b

Equivalently, if a and b are different elements of the domain, then their outputs must also be different.

a ≠ b ⇒ f(a) ≠ f(b)

Example

Consider:

f(x) = 2x + 1

If f(a) = f(b), then:

2a + 1 = 2b + 1
2a = 2b
a = b

Therefore, f(x) = 2x + 1 is injective.

Memory Trick: Injective → “No two inputs share an output.”
★

Exam Answer Structure

For an injective-function question, write the definition, mathematical condition, explain that distinct inputs have distinct outputs, provide a mapping or algebraic example, and conclude clearly that the function is one-to-one.

05 • ONTO

Surjective Functions

A surjective function is commonly called an onto function. It reaches every element of its codomain.

Definition

A function f : A → B is called surjective if every element of B has at least one pre-image in A. In other words, every element of the codomain must be reached by the function.

Range = Codomain

A surjective function does not require every output to have only one input. Therefore, a surjective function may be many-to-one.

Example

Let:

A = {1,2,3}
B = {a,b}

Suppose:

1 → a
2 → b
3 → a

Both a and b are reached. Therefore the function is surjective, even though it is not injective.

Injective Focus on repeated outputs.
Surjective Focus on uncovered codomain elements.
Bijective Both conditions must hold.
06 • PERFECT MATCH

Bijective Functions

A bijective function combines the properties of injective and surjective functions.

Bijective = Injective + Surjective

Every element of the codomain has exactly one pre-image.

Why Bijective Functions Matter

Bijective functions create a perfect one-to-one correspondence between two sets. No domain element is left unmapped, and no codomain element is left unused.

This property is particularly important because a function has an inverse function precisely when the mapping is reversible in this sense.

Finite Set Shortcut

When domain and codomain are finite sets with the same number of elements, injectivity and surjectivity become equivalent conditions.

|A| = |B|
Injective ⇔ Surjective

Therefore, in this special case, proving either one is enough to establish bijectivity.

07 • FUNCTION OPERATIONS

Composition of Functions

Composition means applying one function after another. It is one of the most important operations involving functions.

Meaning of Composition

Suppose we have two functions: g : A → B and f : B → C. The output of g becomes the input of f. The resulting function is called the composition of f and g.

(f ∘ g)(x) = f(g(x))

The symbol ∘ is read as “composition”. It is important to remember that the function on the right is applied first.

1 Input x
→
2 Apply g
→
3 Apply f
→
4 Final Output

Worked Example

Let:

f(x) = 2x + 1
g(x) = x²

Find (f ∘ g)(x)

First apply g:

g(x) = x²

Now put g(x) into f:

f(g(x))
= f(x²)
= 2x² + 1

Therefore: (f ∘ g)(x) = 2x² + 1

Now find (g ∘ f)(x)

g(f(x))
= g(2x + 1)
= (2x + 1)²

Therefore, generally: f ∘ g ≠ g ∘ f

08 • REVERSING A FUNCTION

Inverse of a Function

An inverse function reverses the action of the original function. It takes an output and returns the corresponding original input.

Meaning of Inverse

If a function maps an input x to an output y, then its inverse maps y back to x. The inverse of f is written as f⁻¹.

f(x) = y
f⁻¹(y) = x

For a function to have an inverse function, the mapping must be reversible. In the usual function setting, bijectivity provides exactly this one-to-one correspondence.

Important Warning

f⁻¹(x) is NOT 1/f(x)

The notation f⁻¹(x) represents the inverse function, whereas 1/f(x) represents the reciprocal.

Steps to Find an Inverse Function

1

Write y = f(x).

2

Interchange x and y.

3

Solve the equation for y.

4

Replace y by f⁻¹(x).

5

Verify if necessary.

Worked Example: Finding an Inverse

Given:

f(x) = 2x + 3

Step 1: Write y = f(x).

y = 2x + 3

Step 2: Interchange x and y.

x = 2y + 3

Step 3: Solve for y.

x - 3 = 2y
y = (x - 3) / 2

Step 4:

f⁻¹(x) = (x - 3) / 2

Therefore the inverse function is f⁻¹(x) = (x − 3)/2.

Verification of an Inverse

A useful way to verify an inverse is to compose the function with its inverse.

f(f⁻¹(x)) = x
f⁻¹(f(x)) = x

If both identities hold on their appropriate domains, the functions correctly undo each other.

09 • COMPUTER SCIENCE

Useful Functions for Computer Science

Functions are not only mathematical objects. They are widely used in algorithms, data structures, programming, complexity analysis, computer graphics and information processing.

01

Exponential Functions

Growth and repeated multiplication

An exponential function is generally written as f(x) = aˣ, where a is positive and a ≠ 1. The variable appears in the exponent, which makes exponential functions fundamentally different from polynomial functions.

f(x) = aˣ

When a > 1, the function represents exponential growth. When 0 < a < 1, it represents exponential decay.

Computer Science Connection

Powers of 2 occur frequently in computing because digital systems use binary representation.

2⁰ = 1
2¹ = 2
2² = 4
2³ = 8
2¹⁰ = 1024

Exponential expressions also appear when describing brute-force search spaces and combinations.

02

Logarithmic Functions

The inverse of exponential growth

A logarithm tells us the exponent to which a base must be raised to obtain a particular number.

logb(x) = y ⇔ bʸ = x

For example:

log₂ 8 = 3

because 2³ = 8.

Why Logs Matter in Computer Science

Logarithmic functions are important in algorithm analysis. Binary search is a classic example: each step can reduce the search space approximately by half.

Binary Search → O(log₂ n)

Logarithms also appear in tree structures, data compression, information theory and divide-and-conquer algorithms.

Product Rule log(ab) = log a + log b
Quotient Rule log(a/b) = log a − log b
Power Rule log(aⁿ) = n log(a)
Change of Base logba = log a / log b
03

Polynomial Functions

Expressions involving non-negative integer powers

A polynomial function is a function of the form:

f(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀

Here n is a non-negative integer and the coefficients are constants. The highest exponent with a non-zero coefficient is called the degree of the polynomial.

Constant f(x) = 5
Linear f(x) = 2x + 1
Quadratic f(x) = x² + 3x + 2
Cubic f(x) = x³ − x
Computer Science:

Polynomial functions are frequently used when describing polynomial-time algorithms such as O(n), O(n²), O(n³), and related complexity classes.

10 • INTEGER FUNCTIONS

Floor and Ceiling Functions

Floor and ceiling functions convert real numbers into integers according to two different rounding rules.

⌊x⌋

Floor Function

Greatest integer function

The floor of a real number x is the greatest integer that is less than or equal to x.

⌊x⌋ = greatest integer ≤ x

⌊3.7⌋ = 3

⌊5⌋ = 5

⌊−2.3⌋ = −3

⌈x⌉

Ceiling Function

Smallest integer function

The ceiling of a real number x is the smallest integer that is greater than or equal to x.

⌈x⌉ = smallest integer ≥ x

⌈3.2⌉ = 4

⌈5⌉ = 5

⌈−2.3⌉ = −2

Floor vs Ceiling

x Floor ⌊x⌋ Ceiling ⌈x⌉
3.2 3 4
5 5 5
−2.3 −3 −2
7.9 7 8

⚠ Important: Negative Numbers

The most common mistake is thinking that the floor of −2.3 is −2. That is incorrect.

⌊−2.3⌋ = −3

⌈−2.3⌉ = −2

Remember: floor means moving toward the smaller integer, while ceiling means moving toward the larger integer.

Applications in Computer Science

Pagination

Calculating how many pages are required for a given number of records.

Memory Blocks

Determining the number of blocks required to store data.

Grouping

Dividing objects into fixed-size groups.

Binary Trees

Integer calculations involving levels and heights.

Example

Suppose 53 students need to be divided into groups of 10 students.

⌈53 / 10⌉ = ⌈5.3⌉ = 6

Therefore, 6 groups are required.
